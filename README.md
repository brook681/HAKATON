# Three Body Simulation

**Three Body Simulation** — симулятор гравитационного взаимодействия небесных тел, разработанный на C++ с использованием библиотеки SFML.

Проект позволяет наблюдать за движением тел под действием гравитации, исследовать различные конфигурации системы и моделировать столкновения с последующим слиянием тел.

## Возможности

- Моделирование гравитационного взаимодействия тел.
- Численное интегрирование методом Velocity Verlet.
- Управление скоростью симуляции.
- Запуск, пауза и сброс симуляции.
- Визуализация движения тел в реальном времени.
- Отображение траекторий движения.
- Обнаружение столкновений.
- Слияние тел при столкновении.
- Сохранение суммарной массы и импульса при слиянии.
- Создание собственных начальных условий.
- Автоматизированные тесты физики и симуляции.

## Сценарии симуляции

В приложении реализованы четыре сценария:

1. **Figure Eight (Восьмёрка)** — движение трёх тел по конфигурации с траекториями в форме восьмёрки.
2. **Chaotic (Хаотический)** — конфигурация, демонстрирующая сложное и чувствительное к начальным условиям движение.
3. **Hierarchical (Иерархический)** — два близко расположенных тела и третье тело на удалённой орбите.
4. **Custom (Пользовательский)** — возможность самостоятельно задать начальные параметры трёх тел.

Для пользовательского сценария задаются:
- Масса тела.
- Начальная координата X.
- Начальная координата Y.
- Скорость по оси X.
- Скорость по оси Y.

## Физическая модель

Симуляция основана на законе всемирного тяготения Ньютона.

Для расчёта движения используется метод **Velocity Verlet** с фиксированным временным шагом.

При столкновении тела объединяются в одно новое тело.

При слиянии рассчитываются:
- Общая масса.
- Положение центра масс.
- Скорость на основе закона сохранения импульса.
- Новый радиус на основе суммарной площади поперечного сечения.

## Сборка проекта

Необходимые инструменты:
- Компилятор C++.
- CMake.
- SFML.

Конфигурация:

```bash
cmake -S . -B build
```

Сборка:

```bash
cmake --build build --config Release
```

Запуск в Windows:

```powershell
.\build\Release\ThreeBodySimulation.exe
```

# Симуляция трёх тел

Проект на C++17, моделирующий гравитационное взаимодействие трёх тел и отображающий их движение в реальном времени.

## Возможности

- Моделирование гравитационного взаимодействия трёх тел.
- Визуализация движения с помощью SFML 3.
- Отображение траекторий движения всех трёх тел.
- Приостановка и возобновление симуляции.
- Сброс симуляции к начальному состоянию.
- Разделение физики, логики симуляции и графики на отдельные модули.
- Автоматические тесты физики и логики симуляции.

## Используемые технологии

- **C++17** — основной язык программирования.
- **SFML 3** — графика и визуализация.
- **CMake** — система сборки проекта.
- **MSVC / Visual Studio** — компилятор и среда разработки.
- **vcpkg** — управление зависимостями.

## Управление

| Клавиша | Действие |
|---|---|
| `Space` | Пауза / продолжение симуляции |
| `R` | Сброс симуляции |
| `Escape` | Закрыть приложение |

## Структура проекта

```text
ThreeBodyProject/
├── src/
│   ├── physics/       # Физическая модель
│   ├── simulation/    # Логика симуляции
│   └── graphics/      # Графика и визуализация
├── tests/             # Автоматические тесты
├── main.cpp           # Точка входа
└── CMakeLists.txt     # Конфигурация сборки
```

## Требования

- Компилятор с поддержкой C++17.
- CMake версии 3.20 или новее.
- vcpkg.
- SFML 3 с компонентами Graphics и Window.

## Сборка и запуск (Windows)

### 1. Установка SFML

```powershell
C:\vcpkg\vcpkg.exe install sfml[graphics,window] --triplet x64-windows
```

### 2. Конфигурация проекта

```powershell
cmake -S . -B build -DCMAKE_TOOLCHAIN_FILE=C:/vcpkg/scripts/buildsystems/vcpkg.cmake -DVCPKG_TARGET_TRIPLET=x64-windows
```

### 3. Сборка

```powershell
cmake --build build --config Release
```

### 4. Запуск

```powershell
.\build\Release\ThreeBodySimulation.exe
```

## Запуск тестов

Тесты физической модели:

```powershell
.\build\Release\physics_tests.exe
```

Тесты логики симуляции:

```powershell
.\build\Release\simulation_tests.exe
```
